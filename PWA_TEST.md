## Как протестировать PWA локально:

### 1. Запустите веб-версию:

```bash
npm run web
```

Откройте в браузере: `http://localhost:8081`

### 2. Проверьте PWA в Chrome DevTools:

1. Откройте DevTools (F12)
2. Перейдите в **Application** → **Manifest**
   - Проверьте, что манифест загружается
   - Убедитесь, что все поля заполнены
3. Перейдите в **Application** → **Service Workers**
   - Проверьте, что Service Worker зарегистрирован
4. Запустите **Lighthouse** → **PWA аудит**
   - Должен показать оценку PWA

### 3. Проверьте установку на устройстве:

#### Android (Chrome):
1. Откройте сайт в Chrome
2. Нажмите меню (3 точки) → **"Добавить на главный экран"**
3. Приложение установится как PWA

#### iOS (Safari):
1. Откройте сайт в Safari
2. Нажмите кнопку "Поделиться" → **"На экран Домой"**
3. Приложение установится как PWA

### 4. Проверьте офлайн-режим:

1. В DevTools → **Network** → выберите **Offline**
2. Обновите страницу
3. Приложение должно работать (благодаря Service Worker)

## Известные ограничения на веб:

1. **DateTimePicker** - может работать по-другому на веб
2. **Gesture handlers** - некоторые жесты могут не работать
3. **File picker** - работает через стандартный HTML input

## Следующие шаги:

1. **Соберите для продакшена:**
   ```bash
   npx expo export:web
   ```

2. **Разверните на хостинге:**
   - Netlify: `netlify deploy --dir=web-build`
   - Vercel: `vercel --prod web-build`
   - Или любой другой статический хостинг

3. **Проверьте HTTPS:**
   - PWA работает только через HTTPS (или localhost)
   - Убедитесь, что ваш хостинг поддерживает HTTPS

## Полезные команды:

```bash
# Запустить веб-версию
npm run web

# Собрать для продакшена
npx expo export:web

# Проверить размер сборки
du -sh web-build
```
