# Настройка in-app товара в Google Play Console

В приложении ожидается **разовая покупка (managed / in-app)**, не подписка.

- **Product ID в коде:** `premium_lifetime` (`services/purchases.ts` → `PREMIUM_PRODUCT_ID_ANDROID`)
- **Application ID:** `com.drinknote.app` (должен совпадать с приложением в консоли)

## 1. Подготовка приложения в консоли

1. Откройте [Google Play Console](https://play.google.com/console) → ваше приложение **DrinkNote** (`com.drinknote.app`).
2. Убедитесь, что есть **хотя бы один черновик приложения** (загруженный AAB/APK) и заполнены обязательные разделы (контент, политика и т.д.), иначе часть функций биллинга может быть недоступна.

## 2. Создать товар

1. В меню слева: **Monetize** (Монетизация) → **Products** → **In-app products** (или **One-time products** — название может отличаться по языку/версии консоли).
2. Нажмите **Create product** / **Создать продукт**.
3. **Product ID** задайте **`premium_lifetime`** — **буква в букву** как в коде. После сохранения ID **нельзя** изменить; при ошибке создайте новый продукт и обновите константу в коде.
4. Заполните **название** и **описание** (для пользователя в сторе).
5. Установите **цену** (и при необходимости регионы) — без цены товар часто не становится полностью активным.

## 3. Активировать товар

1. Сохраните продукт и доведите его до статуса **Active** / **Активен** (в консоли будет явно указано).
2. После создания или изменений Google иногда применяет их **с задержкой (от минут до нескольких часов)** — если в приложении «товар не найден», подождите и повторите.

## 4. Не перепутать тип

- Нужен тип **разовой покупки** (in-app / one-time / managed).
- Если создать **подписку** (subscription) с тем же ID, биллинг для покупки как in-app **не сработает** — приложение запрашивает именно разовую покупку.

## 5. Тестирование покупки

1. **Testing** → **Internal testing** (или Closed testing): загрузите туда ту же сборку, что в проде по подписи/пакету, и установите приложение **по ссылке из Play** (не «голый» APK с компьютера, если хотите полный цикл Billing).
2. **Settings** (шестерёнка) → **License testing**: добавьте Gmail тестировщика.
3. На устройстве войдите в Play под **этим же** аккаунтом.
4. Тестовые покупки для лицензированных тестеров **не списывают реальные деньги** (см. актуальную справку Google по «license testing»).

## 6. Если товар «не найден» в приложении

Проверьте по чеклисту:

| Проверка | Действие |
|----------|----------|
| Product ID | В консоли = `premium_lifetime` |
| Тип | In-app / one-time, не subscription |
| Статус | Active, цена задана |
| Установка | Из трека Play (internal/closed) |
| Аккаунт | В License testing |
| Пакет | `com.drinknote.app` = приложение в консоли |
| Время | Подождать после создания товара |

Подробнее про сборку и загрузку AAB: [GOOGLE_PLAY_RELEASE.md](./GOOGLE_PLAY_RELEASE.md).
