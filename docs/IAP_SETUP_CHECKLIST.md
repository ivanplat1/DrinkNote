# Чеклист настройки покупок в приложении

## ✅ После подтверждения аккаунта Google Play

### 1. Создание приложения
- [ ] Создать приложение в Play Console
- [ ] Заполнить базовую информацию (название, описание)
- [ ] Указать тип: Бесплатное приложение с покупками внутри

### 2. Настройка продукта премиума
- [ ] Перейти в **Монетизация** → **Покупки в приложении**
- [ ] Создать продукт:
  - ID: `premium_lifetime` (точно как в коде!)
  - Тип: **Управляемый продукт** (Managed product)
  - Название: Премиум
  - Описание: Одноразовая покупка для разблокировки всех функций
  - Цена: выбрать цену
  - Статус: **Активен**

### 3. Тестирование
- [ ] Добавить тестовые аккаунты в **Лицензионное тестирование**
- [ ] Загрузить AAB во **Внутреннее тестирование**
- [ ] Установить приложение на тестовое устройство
- [ ] Протестировать покупку премиума
- [ ] Протестировать восстановление покупок

### 4. Проверка кода
- [ ] Убедиться, что Product ID в `services/purchases.ts` = `premium_lifetime`
- [ ] Проверить логи при покупке (должны быть информативные сообщения)

### 5. Готово к продакшену
- [ ] Все тесты пройдены успешно
- [ ] Покупка работает корректно
- [ ] Восстановление покупок работает
- [ ] Премиум функции активируются после покупки

## 🔍 Проверка Product ID

**Файл**: `services/purchases.ts`
```typescript
export const PREMIUM_PRODUCT_ID = Platform.select({
  android: 'premium_lifetime', // ← Должен совпадать с Play Console!
  ...
});
```

## 📝 Типичные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| "In-app purchases not available" | Приложение не опубликовано | Загрузить AAB во внутреннее тестирование |
| "Product may not be configured" | Неверный Product ID | Проверить совпадение ID в коде и консоли |
| "Purchase failed" | Продукт не активен | Проверить статус продукта в консоли |
