# Настройка покупок в приложении (In-App Purchases) в Google Play Console

## Шаг 1: Подтверждение аккаунта (в процессе)

После подтверждения адреса и аккаунта вы сможете:
- Создать приложение в Play Console
- Настроить покупки в приложении
- Загрузить AAB для тестирования

## Шаг 2: Создание приложения

1. Войдите в [Google Play Console](https://play.google.com/console)
2. Нажмите **"Создать приложение"**
3. Заполните:
   - **Название приложения**: DrinkNote
   - **Язык по умолчанию**: Русский
   - **Тип приложения**: Приложение
   - **Бесплатное или платное**: Бесплатное (покупки внутри приложения)

## Шаг 3: Настройка покупки премиума

### 3.1. Создание продукта

1. В Play Console перейдите в ваше приложение
2. **Монетизация** → **Покупки в приложении** → **Создать продукт**
3. Заполните форму:

| Поле | Значение |
|------|----------|
| **ID продукта** | `premium_lifetime` (должен совпадать с кодом!) |
| **Название** | Премиум (или "DrinkNote Premium") |
| **Описание** | Одноразовая покупка для разблокировки всех премиум функций |
| **Тип продукта** | **Управляемый продукт** (Managed product) |
| **Цена** | Выберите цену (например, 299₽ или $4.99) |
| **Статус** | Активен |

### 3.2. Важно!

- **ID продукта** должен быть **точно** `premium_lifetime` (без пробелов, регистр важен)
- Тип: **Managed product** (управляемый продукт) - для одноразовых покупок
- Не используйте **Subscription** (подписка) - это для повторяющихся платежей

## Шаг 4: Тестирование покупок

### 4.1. Добавление тестовых аккаунтов

1. **Настройки** → **Управление аккаунтом** → **Лицензионное тестирование**
2. Добавьте email-адреса тестеров (до 20 аккаунтов)
3. Эти аккаунты смогут тестировать покупки без реального списания денег

### 4.2. Тестовые карты Google

Для тестирования можно использовать тестовые карты:
- **Успешная покупка**: `4111 1111 1111 1111` (любая дата, любой CVC)
- **Отклоненная покупка**: `4000 0000 0000 0002`

### 4.3. Внутреннее тестирование

1. **Тестирование** → **Внутреннее тестирование**
2. Создайте релиз и загрузите AAB
3. Добавьте тестовые аккаунты
4. Тестеры смогут установить приложение и протестировать покупки

## Шаг 5: Проверка в коде

Убедитесь, что Product ID совпадает:

**Файл**: `services/purchases.ts`
```typescript
export const PREMIUM_PRODUCT_ID = Platform.select({
  android: 'premium_lifetime', // ← Должен совпадать с Play Console!
  ios: 'premium_lifetime_ios',
  default: 'premium_lifetime',
});
```

## Шаг 6: Типичные проблемы

### Проблема: "In-app purchases not available"
**Решение**: 
- Убедитесь, что приложение опубликовано хотя бы во внутреннем тестировании
- Проверьте, что Product ID точно совпадает
- Убедитесь, что аккаунт добавлен в лицензионное тестирование

### Проблема: "Purchase failed"
**Решение**:
- Проверьте статус продукта в Play Console (должен быть "Активен")
- Убедитесь, что используется правильный Product ID
- Проверьте интернет-соединение

### Проблема: Покупка проходит, но премиум не активируется
**Решение**:
- Проверьте логи в `services/purchases.ts` - там есть обработка покупок
- Убедитесь, что `setPremiumStatus(true)` вызывается после покупки
- Проверьте, что `finishTransactionAsync` вызывается для подтверждения покупки
