# DrinkNote

## Рабочая директория (один источник правды)

- **Вся разработка, тесты и сборки** делаются **только в корне одного клона** этого репозитория — той папки, где лежат `package.json`, `app.json`, `android/` (после prebuild) и т.д.
- **Не смешивайте** параллельно несколько копий проекта (разные worktree / дубликаты папок) для одних и тех же правок: иначе легко закоммитить не то, собрать APK не из тех файлов или потерять `android/`-настройки.
- В инструкциях ниже пути **относительные** от корня (`./android`, `./docs/...`). Подставляйте свой абсолютный путь к корню клона в Cursor/терминале, но **используйте одну и ту же папку** для IDE и для `npm` / `gradlew` / `adb`.

### Команды из корня

```bash
npm install
npm run start
cd android && ./gradlew bundleRelease   # AAB, если уже есть android/
```

Подробнее про загрузку в Google Play: [`docs/GOOGLE_PLAY_RELEASE.md`](./docs/GOOGLE_PLAY_RELEASE.md).
