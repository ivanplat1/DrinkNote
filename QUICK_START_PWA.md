# Быстрый старт PWA для DrinkNote

## ✅ Текущий статус

- Веб-сервер запущен: `http://localhost:8081`
- PWA конфигурация добавлена в `app.json`
- Приложение готово к тестированию

## 🚀 Тестирование PWA

### Шаг 1: Откройте в браузере

Откройте: **http://localhost:8081**

### Шаг 2: Проверьте PWA в Chrome DevTools

1. Нажмите `F12` или `Cmd+Option+I` (Mac) / `Ctrl+Shift+I` (Windows)
2. Перейдите в **Application** → **Manifest**
   - Должен быть виден манифест с настройками PWA
   - Проверьте иконку, название, цвета
3. Перейдите в **Application** → **Service Workers**
   - Должен быть зарегистрирован Service Worker
4. Запустите **Lighthouse** (вкладка в DevTools)
   - Выберите **Progressive Web App**
   - Нажмите **Generate report**
   - Должна быть оценка PWA (обычно 80-100)

### Шаг 3: Установите PWA на устройство

#### Android (Chrome):
1. Откройте `http://localhost:8081` в Chrome на Android
2. Нажмите меню (3 точки) → **"Добавить на главный экран"**
3. Приложение установится как PWA

#### iOS (Safari):
1. Откройте `http://localhost:8081` в Safari на iOS
2. Нажмите кнопку **"Поделиться"** (квадрат со стрелкой)
3. Выберите **"На экран Домой"**
4. Приложение установится как PWA

### Шаг 4: Проверьте офлайн-режим

1. В Chrome DevTools → **Network**
2. Выберите **Offline** (галочка)
3. Обновите страницу (`Cmd+R` / `Ctrl+R`)
4. Приложение должно работать офлайн

## 📦 Сборка для продакшена

Когда будете готовы опубликовать:

```bash
# Соберите статическую версию
npx expo export:web

# Это создаст папку web-build с готовым PWA
```

## 🌐 Развертывание

### Вариант 1: Netlify (рекомендуется, бесплатно)

```bash
# Установите Netlify CLI
npm install -g netlify-cli

# Разверните
netlify deploy --dir=web-build

# Для постоянного развертывания
netlify deploy --prod --dir=web-build
```

### Вариант 2: Vercel (бесплатно)

```bash
# Установите Vercel CLI
npm install -g vercel

# Разверните
vercel --prod web-build
```

### Вариант 3: GitHub Pages

1. Загрузите содержимое `web-build` в репозиторий
2. Включите GitHub Pages в настройках репозитория
3. Выберите папку с файлами

## ⚠️ Важно для продакшена

1. **HTTPS обязателен** — PWA работает только через HTTPS (или localhost)
2. **Проверьте манифест** — все поля должны быть заполнены
3. **Service Worker** — должен быть зарегистрирован
4. **Иконки** — должны быть всех размеров
